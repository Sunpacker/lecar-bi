# Portfolio Completion Target

[Индекс roadmap](README.md)

Этот список задаёт охват демонстрации и не разрешает пропускать промежуточные этапы roadmap.

Для сильной демонстрации должны быть завершены как минимум Phase 1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 13, 17 и 18.

Демонстрационный сценарий:

1. открыть sales dashboard;
2. применить shared filters;
3. сделать drill-down;
4. открыть inventory health;
5. показать ABC/XYZ;
6. открыть custom dashboard;
7. изменить layout widgets;
8. импортировать dataset;
9. показать async import progress;
10. показать inventory alert;
11. открыть `docs/architecture/` и объяснить ключевые решения;
12. показать tests;
13. объяснить, как Outbox позволяет выделять будущие microservices.

Такой сценарий демонстрирует product thinking, frontend engineering, backend architecture, DDD, analytics modeling, async processing и microservice readiness в одной системе.
