# Пользовательская база знаний AutoBI

Этот каталог содержит только опубликованные пользовательские материалы, разрешённые для RAG.
Состав корпуса фиксирует `manifest.json`; никакие другие файлы репозитория не индексируются.

Корпус русскоязычный, технические английские термины сохранены там, где их видит интерфейс.
Изменение текста требует новой revision документа и manifest.
