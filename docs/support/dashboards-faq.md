# Дашборды и частые вопросы

## Дашборды

В разделе «Дашборды» пользователь с правом управления создаёт дашборд, добавляет виджеты и
настраивает их положение. Сохранённые представления хранят набор фильтров для повторного открытия.

## Почему нет ответа по моим продажам?

Чат поддержки объясняет интерфейс и методики по опубликованной документации. Он не читает
фактические BI данные рабочего пространства. Для значений продаж используйте обзор продаж и его
фильтры.

## Почему источник недоступен?

Материал мог быть отозван после создания ответа. История сохраняет безопасное название источника,
но текст и URL отозванного материала больше не выдаются.

## Как задать уточнение?

Каждый вопрос должен быть самостоятельным. Вместо «а это где?» напишите, какой раздел или показатель
вы ищете. История доступна для чтения, но в MVP не передаётся модели как контекст.
