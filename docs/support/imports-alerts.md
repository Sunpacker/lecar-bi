# Импорты и алерты

## Импорт данных

Раздел «Импорты» принимает поддерживаемые наборы данных и показывает статус обработки. Ошибки
валидации доступны в карточке импорта с номером строки и причиной. Повторный запуск доступен только
для неуспешного импорта и требует возможности управления импортами.

## Алерты

Правило алерта задаёт показатель, условие, порог и важность. Включённые правила проверяются
backend. Сработавший алерт можно подтвердить, а затем закрыть с пояснением. Уведомления доставляются
асинхронно, поэтому временная задержка не меняет состояние самого алерта.
