# Phase 11 — Supplier Analytics

[Индекс и правила roadmap](README.md) · [Маршрутизатор агентов](../../AGENTS.md)

## Цель

Добавить третью крупную аналитическую область.

## Функциональность

Supplier overview, delivery count, lead time, delay rate, fulfillment rate, defect/return metric при наличии, trends, drill-down, filters.

## Exit Criteria

Metric definitions явны, calculations backend-owned, interaction conventions едины, tests покрывают расчёты.
