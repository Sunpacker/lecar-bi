# Portfolio Completion Target

[Roadmap index](ROADMAP.md)

This list defines the demonstration scope and does not authorize skipping intermediate roadmap phases.

For a strong demonstration, at least Phases 1, 2, 3, 4, 5, 6, 7, 8, 10, 12, 13, 17, and 18 must be complete.

Demonstration scenario:

1. open the sales dashboard;
2. apply shared filters;
3. drill down;
4. open inventory health;
5. show ABC/XYZ;
6. open a custom dashboard;
7. change the widget layout;
8. import a dataset;
9. show async import progress;
10. show an inventory alert;
11. open `docs/architecture/` and explain key decisions;
12. show tests;
13. explain how Outbox enables future microservice extraction.

This scenario demonstrates product thinking, frontend engineering, backend architecture, DDD, analytics modeling, async processing, and microservice readiness in one system.
