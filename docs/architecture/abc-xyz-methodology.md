# Методология совмещенного ABC/XYZ анализа

Документ фиксирует математические формулы, алгоритмы классификации, граничные условия и бизнес-стратегии управления запасами для совмещенного ABC/XYZ анализа в платформе AutoBI.

---

## 1. Назначение и контекст

Совмещенный ABC/XYZ анализ предназначен для категорийных менеджеров, специалистов по закупкам и логистов автобизнеса. Он позволяет разделить многотысячную номенклатуру запчастей и расходных материалов на 9 управляемых сегментов:
- **ABC-анализ** оценивает **вклад каждого товара в оборот компании** (выручку) по закону Парето.
- **XYZ-анализ** оценивает **стабильность и предсказуемость спроса** на товар через коэффициент вариации расхода/продаж во времени.
- **Матрица 3×3 (AX...CZ)** задает стратегию пополнения, нормирования страхового запаса и снижения риска образования неликвидов.

---

## 2. Алгоритм ABC-анализа (по выручке)

### 2.1. Входные данные
Для каждого товара $i$ за выбранный аналитический период ($T \in \{30, 90, 180, 365\}$ дней) рассчитывается суммарная выручка от продаж:
$$R_i = \sum_{k=1}^{M_i} (\text{quantity}_{i,k} \times \text{unit\_price}_{i,k})$$

Общая выручка анализируемого каталога:
$$R_{\text{total}} = \sum_{i=1}^{N} R_i$$

### 2.2. Доля и сортировка
1. Для каждой позиции вычисляется индивидуальная доля в общей выручке:
   $$\text{share}_i = \begin{cases} \frac{R_i}{R_{\text{total}}}, & \text{если } R_{\text{total}} > 0 \\ 0, & \text{если } R_{\text{total}} = 0 \end{cases}$$
2. Все товары сортируются по убыванию выручки ($R_i \downarrow$). При равенстве выручки применяется дополнительный критерий стабильности сортировки (по названию или артикулу).
3. Рассчитывается накопленная (кумулятивная) доля выручки с нарастающим итогом:
   $$\text{cum\_share}_m = \sum_{j=1}^{m} \text{share}_j$$

### 2.3. Пороговые значения классов
- **Класс A (высокая ценность):** позиция относится к классу A, если предыдущая накопленная доля $\text{cum\_share}_{m-1} < 0.80$ (80%). Товары этого класса обеспечивают первые 80% выручки.
- **Класс B (умеренная ценность):** позиция относится к классу B, если предыдущая накопленная доля находится в диапазоне $[0.80; 0.95)$ (80%–95%).
- **Класс C (низкая ценность):** позиция относится к классу C, если предыдущая накопленная доля $\ge 0.95$ (95%), либо товар не имел продаж за период ($R_i = 0$).

## 3. Алгоритм XYZ-анализа (по вариативности спроса)

### 3.1. Дискретизация временного ряда
Период анализа разбивается на равные подпериоды (бакеты) для устранения внутринедельного шума и получения статистически надежной выборки:
- Для периода 30 дней: 4-5 недельных бакетов ($n \ge 4$).
- Для периода 90 дней: 12-13 недельных бакетов ($n \approx 12$).
- Для периода 180 дней: 6 месячных бакетов ($n = 6$).
- Для периода 365 дней: 12 месячных бакетов ($n = 12$).

Вектор продаж товара в штуках по интервалам времени: $X = (x_1, x_2, \dots, x_n)$, где $x_j$ — количество единиц товара, проданных в $j$-м интервале.

### 3.2. Статистические формулы
1. **Среднеарифметический спрос за интервал:**
   $$\bar{x} = \frac{1}{n} \sum_{j=1}^{n} x_j$$

2. **Выборочное стандартное отклонение:**
   $$s = \sqrt{\frac{1}{n - 1} \sum_{j=1}^{n} (x_j - \bar{x})^2}$$

3. **Коэффициент вариации (Coefficient of Variation, $CV$):**
   $$CV = \begin{cases} \frac{s}{\bar{x}} \times 100\%, & \text{если } \bar{x} > 0 \\ \infty, & \text{если } \bar{x} = 0 \end{cases}$$

### 3.3. Пороговые значения классов
- **Класс X ($CV \le 15\%$):** стабильный, предсказуемый спрос с минимальными колебаниями. Высокая точность прогнозирования.
- **Класс Y ($15\% < CV \le 35\%$):** умеренная вариативность спроса, выраженная сезонность, акции или плановые волны закупок. Средняя точность прогнозирования.
- **Класс Z ($CV > 35\%$ или суммарные продажи = 0):** нерегулярный, стохастический спрос, редкие единичные продажи, высокая степень неопределенности.

## 4. Матрица совмещенной сегментации (9 групп)

| Группа | Сегмент | Характеристика | Стратегия управления запасами |
| :---: | :---: | :--- | :--- |
| **AX** | Ключевые стабильные | Высокая выручка, предсказуемый спрос | **Just-in-Time**, автоматические заказы фиксированными интервалами, минимальный страховой запас. Недопустим дефицит (Stockout). |
| **AY** | Ключевые сезонные | Высокая выручка, сезонные колебания | Страховой запас для демпфирования пиков, динамический пересмотр точки заказа с учетом сезонности. |
| **AZ** | Ключевые нерегулярные | Высокая выручка, редкие крупные сделки | Индивидуальный контроль, заказ под клиента или минимальный страховой буфер. Высокий риск заморозки капитала при ошибке. |
| **BX** | Средние стабильные | Умеренная выручка, стабильный спрос | Регулярные поставки стандартными партиями (EOQ), периодический контроль параметров пополнения. |
| **BY** | Средние сезонные | Умеренная выручка, колебания спроса | Гибкие размеры партий с учетом сезонных коэффициентов, умеренный страховой буфер. |
| **BZ** | Средние нерегулярные | Умеренная выручка, редкий спрос | Поставки по фактическим заявкам или консолидация заказов поставщикам. Минимизация складского остатка. |
| **CX** | Низкие стабильные | Низкая выручка, постоянный расход | Поставки крупными партиями с редкой периодичностью, упрощенный документооборот и автоматическое пополнение. |
| **CY** | Низкие сезонные | Низкая выручка, сезонные колебания | Снижение неснижаемого остатка, закупка строго к началу сезона, ревизия целесообразности поддержания остатка. |
| **CZ** | Низкие неликвиды | Низкая выручка, спонтанный спрос | Кандидаты на распродажу и вывод из матрицы. Работа строго под индивидуальный заказ клиента со склада поставщика. |

## 5. Граничные и особые случаи

1. **Каталог без продаж за период ($R_{\text{total}} = 0$):**
   - Все товары классифицируются как **CZ** ($\text{share} = 0$, $CV = \text{null}$ или $100\%$).
   - Выручка равна $0$, остатки отражаются по фактическим складским данным.
2. **Товар с нулевыми продажами при ненулевом общем обороте:**
   - Автоматически получает класс **C** и класс **Z** (группа **CZ**).
3. **Единственный временной бакет ($n \le 1$):**
   - Расчет стандартного отклонения по формуле несмещенной дисперсии ($n-1$) невозможен. $s = 0$, $CV = 0\%$, позиция относится к классу **X**.
4. **Все бакеты имеют одинаковые ненулевые продажи ($x_1 = x_2 = \dots = x_n$):**
   - $s = 0$, $CV = 0\%$, позиция относится к классу **X**.
5. **Товары с отрицательной или нулевой себестоимостью:**
   - Исключаются из расчета стоимости запасов или принимаются равными 0 для предотвращения искажения оборотного капитала.
