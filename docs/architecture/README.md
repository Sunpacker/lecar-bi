# AutoBI Architecture Documentation

Эта директория содержит архитектурную документацию проекта.

Документация фиксирует базовые решения по структуре системы, границам сервисов, DDD-подходу в Laravel, устройству аналитического слоя, интеграциям, инфраструктуре и дальнейшему развитию.

## Состав документации

- `00-overview.md` — назначение продукта и ключевые архитектурные принципы.
- `01-system-architecture.md` — общая архитектура системы и ответственность компонентов.
- `02-monorepo-and-services.md` — устройство монорепозитория и правила изоляции сервисов.
- `03-frontend-nextjs.md` — архитектурные установки для Next.js-приложения.
- `04-backend-laravel-ddd.md` — DDD-архитектура Laravel-микросервиса.
- `05-bounded-contexts.md` — начальные bounded contexts и правила их развития.
- `06-data-and-analytics.md` — хранение данных, аналитические модели и read-heavy подход.
- `07-api-and-integration.md` — API-контракты и взаимодействие между сервисами.
- `08-events-outbox-async.md` — доменные события, интеграционные события и асинхронные процессы.
- `09-infrastructure-deployment-observability.md` — инфраструктура, деплой и наблюдаемость.
- `10-testing-and-quality.md` — стратегия тестирования и архитектурные ограничения.
- `11-evolution-and-roadmap.md` — принципы эволюции системы и этапы развития.
- `12-architecture-decisions.md` — зафиксированные архитектурные решения.

## Статус

Документация описывает целевую архитектуру версии 1 и служит базовой точкой отсчёта для дальнейших изменений.

Все существенные изменения архитектуры должны сопровождаться обновлением соответствующего документа и, при необходимости, отдельным ADR.
